# Changelog

## 0.3.0 (beta) — 2026-10-30

The first public release. Yami is in beta: expect rough edges, and please [report bugs](https://github.com/sico-vibes/Yami/issues/new/choose) (Settings › Your data › Report a bug collects a report for you).

### Highlights

- **Choose your Yami.** First-run setup with presets (Essentials, Developer, Tinkerer, Everything) or your own pick. Every feature is a module you can switch on or off later; modules that are off do not load.
- **Voice and dictation.** Talk to Yami or dictate into any app with Gemini, Windows speech, or fully offline with Whistle. Live captions, your own word list, and accent characters.
- **The island.** Media controls with lyrics, Today (calendar, holidays, weather and air quality, timers, keep awake), system stats, clipboard history, apps, wallpapers, internet radio and power.
- **File wheel.** Drag a file and tap a key to convert, compress, rename, OCR or edit images, documents, audio and video; folder actions; watch folders.
- **Tune.** Windows tweaks with exact undo, startup apps, DNS and DNS over HTTPS, a local ad-blocking network shield, cleanup, disk space, installed apps, the hosts file, environment variables, mouse pointers and an administrator section.
- **For developers.** Projects with branch status, one-click coding agents, a terminal with panes and shell integration, parallel tasks on git worktrees, agent status in the island, and "Yami for your agents" over MCP.
- **Desk.** Plans and to-dos, a Feeds inbox (RSS, Bluesky, Mastodon, podcasts), a mail glance, and a download manager with multi-connection downloads.
- **Yami Browser.** A light private browser with blocking, reader view, a local vault, and a linked mode for sites that need your real browser.
- **Desktop.** A dock with an option to hide the taskbar, a desk widget with clock styles, a roaming spirit, Yami Home (a new-tab page extension), and Yami Remote for your phone.
- **Logs and bug reports.** Agent-friendly logs (activity, errors, triage and debug), one-click reports with secrets masked, and tools that let a coding agent read Yami's status and logs.

### Good to know

- The download is a portable `.exe` and is not signed yet, so Windows SmartScreen asks before the first run: **More info › Run anyway**.
- Online features use accounts you connect yourself. Free tiers have their own limits and terms.
- Idle memory is about 150 MB with the default modules.
