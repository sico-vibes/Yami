## Generation and distribution

The built-in image-generation tool created each landscape separately from a shared environmental-art brief and a distinct scene prompt. No reference images were supplied. Native 1536 × 1024 outputs were resampled to 1920 × 1280 and encoded as JPEGs; this export adds no new source detail. The ten files together occupy approximately 6.3 MB on disk.

The full prompt template, scene prompts, dimensions, generation method and distribution statement live in [the pack manifest](../../public/wallpapers/pack.json). These generated assets are included with Yami's MIT distribution to the extent copyright applies. They replace the borrowed reference wallpapers in the shipped pack; the MIT license does not grant rights to third-party reference assets.

## Add or revise a pack

Keep environment artwork separate from character artwork. Add provenance and dimensions to the manifest, inspect the exported file at full size, and check that it works behind desktop icons. Wallpaper images should not be decoded continuously while Yami is idle. The app displays the selected library images on demand; it does not animate this pack.

Personal folders remain available through **Wallpaper → Choose wallpaper folder**. Imported paths and images stay local unless a separate feature explicitly sends a screen capture to a provider. Switching wallpapers must be checked in Windows, since the browser preview changes only its fixture state.
