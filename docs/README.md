# Yami documentation

Yami is a free Windows desktop companion. It lives in a small spirit island at the top of your screen, where you can talk to it, dictate text, circle anything on screen to ask about it, and reach a set of Windows tools in one tap. Yami can also help with your day: plans, reminders, the weather, your inbox and your coding agents.

Yami is open source under the MIT License. Every feature is optional, so you can turn on only what you use. Online AI features use your own API keys.
