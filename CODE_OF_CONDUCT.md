# Code of conduct

Yami's community follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and do not harass anyone. Issues, pull requests and discussions that do not follow this may be edited, closed or locked, and repeated problems can lead to a ban from the project.

To report a problem privately, use the repository's private security reporting (Security › Report a vulnerability) and say it is a conduct report.
